Browser4 Extension 隐私政策

本政策说明 Browser4 Extension 处理哪些信息、如何使用这些信息以及您拥有的选择。 它适用于通过 Chrome Web Store 分发的 Browser4 Extension。

产品：Browser4 Extension 产品 ID：jdcmdidbgjeebbhkoepjgifeibipfimi 最后更新：2026年8月5日

1. 概述

Browser4 Extension（"扩展程序"）让您可以控制真实浏览器，使 AI 智能体和自动化工作流能够 代您浏览、自动化、提取和分析网络。我们致力于透明地说明扩展程序如何处理信息。

扩展程序在您的设备上处理数据，不会将您的任务、页面内容、凭据或设置上传到任何服务器。 唯一可能传输的信息是有限的、不具识别性的使用统计信息，详见第 6 节。本政策说明扩展程序 如何处理信息以及您拥有的选择。

扩展程序由武汉市翘曲速率信息科技有限公司（Wuhan Qiaoqu Sulu Information Technology Co., Ltd.）提供，公司位于中国湖北省武汉市东湖新技术开发区。

2. 我们处理的信息

2.1 您提供的信息

使用扩展程序时，您可能提供：

  • 您创建的 URL、任务、提示词和自动化指令；
  • 您作为任务一部分输入的表单值、文本或文件选择；
  • 您主动输入的账户凭据，以便扩展程序完成您要求的登录或需要认证的工作流。

2.2 您指示扩展程序处理的内容

扩展程序会处理您指示其访问的网页内容，以完成您的任务（例如阅读产品页面、填写表单或提取 结构化数据）。此处理代表您并按照您的指示在本地进行。

2.3 统计信息

扩展程序可能收集有限的、聚合的使用统计信息，例如功能使用次数、扩展程序版本以及匿名的性能 或错误率。这些统计信息仅用于改进产品，绝不包括您的 API 密钥、密码、账户凭据、页面内容或 任何其他敏感或个人信息。扩展程序处理的所有其他数据均保留在您的设备上。

2.4 账户信息

扩展程序不要求您登录，也不提供账户或同步功能。它不收集或上传账户、资料或授权信息。

3. 信息的使用方式

我们仅将上述信息用于以下本地目的：

  • 运行扩展程序并执行您发起的任务；
  • 在会话之间保存您的设置和任务状态；
  • 提供客户支持并响应您的请求；
  • 遵守法律义务并保护我们服务的安全。

由于扩展程序在本地处理数据，上述信息均不会因这些目的而传输给我们。我们不会出售您的个人信息， 也不会使用扩展程序处理的内容投放广告。

4. 权限

扩展程序仅申请让 AI 智能体控制真实浏览器所需的浏览器权限。根据您使用的功能，这些权限可能 包括：

  • Tabs（标签页）——读取和控制智能体使用的标签页；
  • Storage（存储）——在您的设备上本地保存设置和任务；
  • Scripting 和 active tab——在您指示扩展程序操作的页面上运行自动化；
  • Host permissions（主机权限）——针对您选择自动化的网站，使智能体能够在 您的指示下导航和交互；
  • Downloads（下载）——保存您要求的文件和导出数据；
  • Web navigation 和 alarms——跟踪进度并运行定时或长时间任务；
  • Notifications（通知）——在任务完成时提醒您。

这些权限仅用于完成您发起的自动化任务，绝不会从您未要求扩展程序处理的页面收集数据。通过这些 权限处理的所有数据都保留在您的设备上，第 6 节所述的聚合统计信息除外。

5. 本地处理与存储

扩展程序在您的设备上本地处理任务。所有设置、任务定义和缓存数据都通过浏览器的存储 API 保存在 本地。除第 6 节所述的有限聚合统计信息外，不会有任何用户数据传输给 Browser4 或任何第三方。 您可以随时通过浏览器设置清除这些数据，卸载扩展程序也会移除其存储的数据。

由于扩展程序可能处理敏感信息（例如凭据或您所处理页面上的个人数据），我们建议您仅提供任务所需 的信息，并避免在已保存的任务中长期保留秘密。

6. 统计与数据上传

所有用户数据——任务、提示词、页面内容、凭据和设置——都在本地处理，绝不会上传到任何服务器。 扩展程序唯一可能传输的信息是有限的聚合使用统计信息，例如：

  • 功能使用次数和聚合交互模式；
  • 扩展程序版本和浏览器版本；
  • 匿名的性能与错误率。

这些统计信息仅用于改进扩展程序，绝不包括您的 API 密钥、密码、账户凭据、页面内容、个人标识符 或任何其他敏感信息，也不会出售或用于广告目的。如果将来引入可选的云连接功能，我们将在进行任何 此类处理前更新本政策并征得您的同意。

7. 分享与披露

由于扩展程序将数据保留在您的设备上，因此不存在可供披露的集中式用户数据存储。除以下情形外， 我们不会披露您的个人信息：

  • 征得您的同意；
  • 法律、法规或司法程序要求时；
  • 在合并、收购或资产转让中，且实际可行时通知您。

8. 数据保留与删除

本地数据将保留到您清除或卸载扩展程序为止。由于扩展程序不上传数据，因此没有服务器端副本需要 删除。您可以随时通过清除扩展程序的浏览器存储或卸载扩展程序来移除所有数据。

9. 安全

由于扩展程序在本地处理数据且不传输到任何服务器，因此不存在可能被泄露的远程数据存储库。 我们仍会在扩展程序的代码和依赖中遵循安全最佳实践，并及时响应已识别的风险或漏洞。

10. 儿童隐私

扩展程序不面向 13 岁以下儿童，我们也不会故意收集儿童的个人信息。如果您认为有儿童向我们提供 了个人信息，请联系我们，我们将予以删除。

11. 政策变更

我们可能不时更新本政策。发生重大变更时，我们会更新本页顶部的"最后更新"日期，并在适当时通过 扩展程序或 browser4.io 网站发出通知。变更生效后继续使用扩展程序即视为接受修订后的政策。

12. 联系我们

如果您对本政策或扩展程序处理您信息的方式有任何疑问，可通过 ivincent.zhang@gmail.com 或 galaxyeye@live.cn 与我们联系，也可通过 browser4.io 上的公开渠道联系，或在官方项目仓库 github.com/platonai/browser4 提交 Issue。我们将在 30 天内回复隐私相关请求。
