Browser4 隐私政策

本政策说明 Browser4 网站（browser4.io）及 Browser4 项目处理哪些信息、如何使用这些信息 以及您拥有的选择。它适用于以 Browser4 名义运营的网站及相关项目服务。 Browser4 Extension 拥有单独的政策。

适用范围：browser4.io 与 Browser4 项目 运营主体：武汉市翘曲速率信息科技有限公司 最后更新：2026年8月6日

1. 概述

Browser4 是为智能体时代打造的浏览器基础设施项目：它提供开源工具、浏览器智能体及自动化能力， 让 AI 智能体能够浏览、自动化、抓取和分析网络。本网站由 武汉市翘曲速率信息科技有限公司（Wuhan Qiaoqu Sulu Information Technology Co., Ltd.）运营， 与 platon.ai 属同一团队。

我们致力于透明地说明网站与项目如何处理信息。本政策说明我们收集哪些信息、为什么收集， 以及您享有的权利。本政策力求简短清晰；文中提到的"我们"指上述运营主体。

2. 本政策的适用范围

本政策涵盖：

  • browser4.io 网站及其子页面；
  • 您通过本网站列出的联系渠道与我们进行的沟通；
  • 本网站上介绍的开源 Browser4 项目及其命令行工具。

本政策不涵盖：

  • 通过 Chrome Web Store 分发的 Browser4 Extension，它由 《Browser4 Extension 隐私政策》 另行规范；
  • 本网站链接到的第三方网站和服务，包括 GitHub、YouTube、Bilibili、微信、微博、Twitter、 npm 以及用于安装包的下载服务器。这些服务按其自身的隐私政策运行。

3. 我们收集的信息

3.1 本地偏好

网站在您浏览器的本地存储（localStorage）中保存少量偏好设置，例如您选择的主题（浅色/深色） 和语言。这些偏好只存储在您的设备上，不会传输给我们，您可以随时通过浏览器设置清除。

3.2 标准网站访问数据

与大多数网站一样，我们的托管基础设施会在您访问时自动接收标准技术数据，例如您的 IP 地址、 浏览器类型与版本、操作系统、访问的页面以及时间戳。我们使用这些数据来保障网站安全、 排查问题并了解大致流量情况。这些数据不会与您可能提供的任何身份信息合并，仅保留安全与运维 所合理需要的时间。

3.3 与我们联系

当您通过电子邮件或我们的公开渠道联系我们时，我们会处理您的发件邮箱地址、您提供的姓名 （如有）以及消息内容，以便回复您的咨询。

3.4 您通过交互功能主动提供的信息

网站目前不提供在线表单、账号或下单系统。如果我们将来增加演示预约、白皮书下载或联系表单等 功能，我们将仅处理您主动提交的信息（例如您的姓名、邮箱和公司），并在启用前先行更新本政策。

4. Cookie 与分析

网站目前不设置自身的 Cookie，也不运行分析或广告追踪。部分页面会嵌入第三方服务的内容 （例如 YouTube 或 Bilibili 的视频播放器、微信二维码图片），部分链接指向第三方网站。 这些第三方可能按其自身的政策设置 Cookie 或处理数据，我们对此无法控制。

5. 信息的使用方式

我们仅将上述信息用于以下目的：

  • 运营、保障并改进网站；
  • 回复您的咨询并提供支持；
  • 履行法律义务并保护我们的合法权益；
  • 开发并改进 Browser4 项目。

我们不会出售您的个人信息，也不会使用网站数据投放广告。

6. 分享与披露

除以下情形外，我们不会披露您的个人信息：

  • 向帮助我们运营网站的服务提供商（例如托管和存储服务）披露，这些服务商按照我们的指示 并代表我们处理数据；
  • 征得您的同意；
  • 法律、法规或司法程序要求时；
  • 在合并、收购或资产转让中，且实际可行时通知您。

7. 数据保留与删除

本地偏好会保留在您的设备上，直到您清除浏览器的本地存储。网站访问数据仅按安全与运维需要 保留。沟通记录按处理您咨询所需的时间保留，并遵守法律义务。您可随时通过下方联系方式请求 删除您向我们提供的信息。

8. 安全

我们采取合理的技术与组织措施保护所处理的信息，包括使用加密连接（HTTPS）。没有任何传输或 存储方式绝对安全，但我们会保持系统与依赖的更新，并及时响应已发现的风险。

9. 您的权利

根据您所在司法辖区的规定，您可能享有访问、更正、删除或反对处理您的个人信息，以及获取我们 所持有信息副本的权利。如需行使这些权利，请通过下方联系方式与我们联系。我们将在 30 天内回复 隐私相关请求。

10. 儿童隐私

网站不面向 13 岁以下儿童，我们也不会故意收集儿童的个人信息。如果您认为有儿童向我们提供了 个人信息，请联系我们，我们将予以删除。

11. Browser4 软件与 Extension

Browser4 项目为开源项目，可在 GitHub 上获取。您安装的项目软件在您自己的基础设施上运行并受您控制；任何云连接功能将在您使用前 通过相应文档和政策另行说明。

Browser4 Extension 是独立产品，具有不同的数据处理方式。如果您使用该扩展，请阅读 《Browser4 Extension 隐私政策》。

12. 政策变更

我们可能不时更新本政策。发生重大变更时，我们会更新本页顶部的"最后更新"日期，并在适当时 在网站上发出通知。变更生效后继续使用网站即视为接受修订后的政策。
